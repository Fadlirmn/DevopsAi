Apa saja batas rate limit dan cara mengubahnya?

API publik dibatasi 60 request per menit per kunci. Kalau lewat batas, server membalas HTTP 429 dengan header Retry-After.

Batas per paket

PaketBatasBurst
Free60 / menit10
Pro600 / menit50
EnterpriseCustomCustom

Cara mengubah

  • Buka Settings → Quota.
  • Isi batas baru, lalu simpan.
  • Perubahan aktif dalam satu menit.
